## 2. 这篇文献研究了什么问题？

### 2.1 Research question / aim

这篇文献的核心目标是构建并发布一个 **基于普通 2D 视频的物理治疗动作数据集 MobiPhysio**，用于支持 AI 驱动的康复动作评估、动作监测和居家康复系统开发。

作者明确提出，该数据集包含：

* 3686 个 segmented videos；
* 9 个 Active Range of Motion 康复动作；
* 58 名男女参与者；
* 专家与非专家参与者；
* 多种真实环境变化，包括光照、相机角度、遮挡、抖动、低分辨率；
* 由物理治疗专家基于 Exercise Accuracy Assessment Questionnaire, EAAQ 给出的动作质量评分。

见 PDF 第 1–3 页 Abstract、Specifications Table 和 Data Description。

---

### 2.2 为什么这个问题重要？

作者认为，很多人，尤其是老年人、受伤者、农村地区人群，难以定期获得物理治疗服务，原因包括距离、治疗师资源有限和成本较高。COVID-19 等疫情期间，这一问题更加突出。作者指出，现有系统如 SAR、KiReS、Exergames 等往往依赖 Kinect 或可穿戴传感器，而这些设备昂贵、复杂，在很多地区难以普及。

因此，作者提出使用普通智能手机或 webcam 的 **2D camera input** 是更可及的方案。MobiPhysio 的价值在于为低成本、居家、AI 辅助康复系统提供数据基础。

对应位置：PDF 第 2 页 “Value of the Data”；第 3 页 “Background”。

### 3.4 测量指标 / 标注指标

本文的核心标注不是骨架关键点，也不是 CVA/head pitch，而是 **Exercise Accuracy Assessment Questionnaire, EAAQ** 产生的动作质量评分。

EAAQ 包含 7 个问题，分为两类：

| 指标类别                | 内容                          |
| ------------------- | --------------------------- |
| Primary Factors, PF | 前 4 个问题，关注是否做对动作、速度、幅度、重复次数 |
| Control Factors, CF | 后 3 个问题，关注姿势与动作质量           |
| 最终评分                | 三名物理治疗师独立评分后取平均，并缩放到 100 分制 |

PDF 第 9 页 Fig. 4 以 Abduction 为例展示了 EAAQ，其中包括：

* Primary objective；
* motion speed；
* amplitude；
* repetition；
* head and trunk alignment；
* arm alignment；
* leg alignment。

这对你的项目非常有参考价值：你可以借鉴它把“单一角度指标”扩展为“多维姿态质量评分”，例如 CVA、head pitch、头前伸距离、躯干前倾、持续时间、恢复动作完成度等。

### 3.5 实验流程

根据 PDF 第 5–8 页和 Fig. 3，流程如下：

1. **Phase I: Consultation with physiotherapists and exercise selection**
   与物理治疗师咨询，最初选择 14 个动作，覆盖 frozen shoulder、low back pain、carpal tunnel syndrome、neck pain、knee pain、tennis elbow 等问题。

2. **Phase I: Non-expert data collection**
   非专家参与者观看物理治疗师示范视频，在实验室环境中模仿完成动作。

3. **Phase II: Exercise modification and assessment questionnaire generation**
   专家重新审查动作集合，将动作缩减为 9 个 Active Range of Motion 动作，并为每个动作制定 exercise-specific questionnaire。

4. **Phase II: Expert data collection and annotation**
   由 physiotherapy-trained participants 执行动作；三名 certified physiotherapists 使用 EAAQ 独立评分。

5. **Dataset analysis**
   分析角度分布、环境变化分布、专家/非专家视频比例、评分分布、评分一致性等。

### 3.6 算法或统计方法

本文不是算法论文，没有训练或测试一个姿态估计模型。统计分析主要用于验证人工评分一致性。

| 方法                                           | 作用                     |
| -------------------------------------------- | ---------------------- |
| Pairwise correlation analysis                | 检查三名 annotators 的评分相关性 |
| Intraclass Correlation Coefficient, ICC(3,k) | 衡量多名评分者之间的可靠性          |
| Mann-Whitney U test                          | 检查评分分布之间是否有显著差异        |
| Mean absolute differences                    | 评估 annotators 之间评分差异大小 |
| Dataset distribution analysis                | 分析视频角度、环境变化、来源、评分分布    |

文中未报告 MediaPipe、DTW、深度学习分类模型、回归模型或姿态估计算法结果。

### 4.3 标注一致性结果

| 结果                               |          数值 | 位置                                        |
| -------------------------------- | ----------: | ----------------------------------------- |

## 5. 这篇文献的贡献

### 5.1 它解决了什么问题？

本文解决的是 **缺少低成本、2D 视频、专家标注、真实环境变化下的康复动作数据集** 的问题。

它提供了一个面向 AI-driven physiotherapy assessment and monitoring 的数据基础，尤其适合研究：

* exercise classification；
* exercise quality assessment；
* movement quality assessment；
* rehabilitation progress monitoring；
* mobile-phone-based home rehabilitation；
* 2D camera-based rehabilitation support systems。

---

### 5.2 相比已有研究的改进

根据 PDF 第 2–3 页，作者认为已有系统或数据集存在如下问题：

* 许多系统依赖 Kinect、RGB-D 或 wearable sensors，成本高、部署复杂；
* 早期工作 exercise variety 窄；
* 参与者人口学范围有限；
* 遮挡处理不足；
* expert-reviewed annotations 不充分。

MobiPhysio 的改进包括：

| 改进点                       | 说明               |
| ------------------------- | ---------------- |
| 使用普通 2D smartphone videos | 更适合低成本居家康复       |
| 包含 expert + non-expert    | 可学习标准动作与常见错误     |
| 多角度拍摄                     | front、left、right |
| 多种真实环境变化                  | 光照、抖动、遮挡、低分辨率    |
| exercise-specific EAAQ    | 每个动作有专家设计的评估问卷   |
| 三名专家独立评分                  | 评分取平均，并报告一致性统计   |

---

### 5.3 对你的项目的启发

#### 对你的系统设计

这篇文献可以支持你论文中的一个关键论点：

> 基于普通 RGB 摄像头的康复监测具有可及性优势，适合居家场景；但要实现可靠评估，需要考虑光照、遮挡、相机角度、动作质量标注和专家评价体系。

#### 对你的方法设计

你可以借鉴它的 EAAQ 思路，设计自己的 **Posture Risk Assessment Questionnaire / Cervical-Spine Posture Scoring Rubric**，例如：

| 你的指标                  | 可借鉴 EAAQ 的方式                         |
| --------------------- | ------------------------------------ |
| CVA                   | 作为头颈姿态核心评分项                          |
| head pitch            | 作为头部前倾/低头评分项                         |
| forward head distance | 作为头前伸程度评分项                           |
| trunk inclination     | 作为躯干前倾评分项                            |
| 持续时间                  | 类似 repetition / duration 的行为约束       |
| 风险等级                  | 可由多个指标加权映射为 low / medium / high risk |

这是基于文献内容的推断，不是作者原文结论。

#### 对你的 Evaluation 设计

本文提醒你：如果你的系统使用人工专家评分作为 ground truth，需要报告 inter-rater reliability，例如：

* ICC；
* Pearson / Spearman correlation；
* Bland-Altman；
* MAE against RGB-D reference；
* mean absolute difference between raters。

不过本文本身没有使用 RGB-D，也没有报告 Bland-Altman 或 MAE against depth sensor。
