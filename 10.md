# PDF 阅读笔记：UCO Physical Rehabilitation Dataset, 2023

以下总结严格基于你上传的 PDF：**Aguilar-Ortega et al., “UCO Physical Rehabilitation: New Dataset and Study of Human Pose Estimation Methods on Physical Rehabilitation Exercises,” Sensors, 2023**。
注意：这篇文献**不是颈椎 / CVA / head pitch 专门论文**，而是关于**康复动作数据集 + 单目 RGB 人体姿态估计方法评测**的论文。它对你的项目最有价值的地方在于：**单目 RGB + HPE + 角度指标 + 外部 3D ground truth 验证 + 相机视角影响分析**。

## 2. 这篇文献研究了什么问题？

### Research question / aim

作者的核心目标是评估**通用 state-of-the-art human pose estimation 方法**在物理康复动作中的可用性。文中明确提出三个目标：

1. 比较多种 2D / 3D 姿态估计方法在康复动作中的表现；
2. 分析**被试姿态**和**相机视角**对估计结果的影响；
3. 判断在康复角度测量中，是否必须使用 3D 姿态估计，还是 2D 姿态估计已经足够。

位置：Abstract，p.1；Introduction，p.2；Figure 1，p.3。

### 为什么这个问题重要？

作者指出，康复训练中很多练习由患者在家中完成，缺少医疗人员实时监督，可能影响动作执行的一致性和质量。基于 RGB 摄像头的计算机视觉方法比 wearable / 专用设备更低侵入、更适合远程康复场景。文中还指出，医生常使用**肢体屈曲角度**作为评估患者活动能力的线索，因此从图像中估计关节位置并计算角度具有实际意义。

位置：Introduction，p.1–2。

## 3. 方法细节

### 3.1 被试 / 数据集 / 样本量

| 项目    | 内容                                        |
| ----- | ----------------------------------------- |
| 数据集名称 | UCO Physical Rehabilitation               |
| 采集时间  | 2022 年 6–7 月                              |
| 被试数量  | 27 名健康被试                                  |
| 性别    | 7 名女性，20 名男性                              |
| 年龄    | 23–60 岁                                   |
| 环境    | 室内、受控环境                                   |
| 动作数量  | 16 个 activities：4 个下肢动作 + 4 个上肢动作，左右两侧各一次 |
| 重复次数  | 每个 activity 做 4 次，低速执行，用于模拟术后或近期受伤后的动作速度  |
| 视频数量  | 2160 段视频                                  |
| 平均时长  | 30.4 s                                    |
| 总帧数   | 约 1.6M frames                             |

位置：Materials，p.3–4；Table 1，p.4。

### 3.2 使用的设备或传感器

| 设备                                 | 用途           | 细节                                            |
| ---------------------------------- | ------------ | --------------------------------------------- |
| 5 个 RGB 摄像头                        | 采集多视角康复动作视频  | 1280 × 720 分辨率；不同视角                           |
| OptiTrack IR motion capture system | ground truth | 6 个 IR 摄像头；用于记录 3D 关节点                        |
| 红外 marker                          | 放置在目标关节上     | 上肢：shoulder, elbow, wrist；下肢：hip, knee, ankle |

作者说明 OptiTrack 提供的 3D ground truth 精度为 **±0.5 mm**。每一帧存储 5 个 RGB 图像帧以及 OptiTrack 返回的 3D ground truth 点；随后通过投影获得 2D ground truth 点。

位置：Materials，p.4–5；Figure 3，p.5。

### 3.3 相机设置

作者使用 5 个 RGB camera，不同高度和角度：

| Camera      | 位置说明                                       |
| ----------- | ------------------------------------------ |
| cam0        | 与 cam1、cam2 水平角度相同；高度 15 cm                |
| cam1        | 与 cam0、cam2 水平角度相同；高度 180 cm               |
| cam2        | 与 cam0、cam1 水平角度相同；高度文中未单独强调，其他摄像头为 100 cm |
| cam3 / cam4 | 侧向或更开放角度；高度 100 cm                         |

位置：Materials，p.4–5；Figure 3，p.5。

### 3.4 测量指标

本文主要测量的是**目标肢体关节的关键点位置误差和屈曲角度误差**，不是 CVA 或颈椎指标。

| 指标                 | 说明                                                                   |
| ------------------ | -------------------------------------------------------------------- |
| 2D keypoint error  | 估计关键点与 2D ground truth 的 Euclidean distance，按治疗床投影长度归一化              |
| 2D joint angle MAE | 用 2D 估计关键点计算角度，与 2D ground truth 角度比较                                |
| 3D joint angle MAE | 用 3D 估计关键点计算角度，与 3D ground truth 角度比较                                |
| FPS                | 各方法处理速度                                                              |
| 统计显著性              | Friedman test, Nemenyi post hoc test, CD diagrams, ANOVA, Tukey test |

位置：Metrics，p.10–11；Implementation Details，p.11–12。

### 3.5 实验流程

作者做了四类实验：

1. **旋转 supine 视频实验**
   由于一些模型在被试仰卧时无法很好检测关节，作者将 supine position 的视频旋转 90°，模拟站立姿态，再比较误差。位置：Experiments，p.9；Figure 6，p.9；Results 5.1，p.12–13。

2. **不同姿态下的模型比较**
   按 supine、seated、standing 三类姿态比较 2D 和 3D 姿态估计方法。位置：Results 5.2，p.13–15。

3. **不同相机视角比较**
   分析 5 个摄像头视角对 keypoint error 和 angle MAE 的影响。位置：Results 5.3，p.15–17；Tables 5–7，p.16。

4. **2D 估计角度 vs 3D ground truth 角度比较**
   用 2D 模型估计的角度与 OptiTrack 3D ground truth 角度比较，用于判断 2D 是否可替代 3D。位置：Results 5.4，p.17–18；Table 8，p.18。

### 3.7 Ground truth 是什么？

本文的 ground truth 是 **OptiTrack IR motion capture system** 返回的 3D 关节点位置。2D ground truth 由 3D ground truth 投影得到。

这和你的项目中计划使用的 **RGB-D sensor 作为 ground truth** 并不完全相同。本文不能直接证明 RGB-D ground truth 的精度，但可以支持你的评估设计：**用外部 3D 测量系统验证单目 RGB 姿态估计误差**。

位置：Materials，p.4–5。

## 4. 主要结果

### 4.1 Supine 姿态对 HPE 是挑战；旋转视频通常改善结果

作者发现，仰卧动作对姿态估计模型更困难。将 supine 视频旋转 90° 后，多数模型在 keypoint 或 angle estimation 上误差降低。

代表性结果如下：

| 方法                          |     原始 supine |           旋转后 | 结果说明   |
| --------------------------- | ------------: | ------------: | ------ |
| AlphaPose 2D keypoint error | 0.044 ± 0.005 | 0.039 ± 0.003 | 改善     |
| AlphaPose 2D angle MAE      | 11.80 ± 2.72° |  9.32 ± 1.36° | 改善     |
| HMR 3D angle MAE            | 20.65 ± 2.45° | 15.56 ± 2.90° | 改善     |
| HybrIK 3D angle MAE         | 17.93 ± 2.34° |  6.86 ± 1.20° | 明显改善   |
| MediaPipe 2D angle MAE      | 13.43 ± 3.50° | 14.23 ± 2.47° | 平均值未改善 |
| VideoPose3D 3D angle MAE    | 17.81 ± 1.81° | 18.17 ± 4.71° | 平均值未改善 |

位置：Table 4，p.12；Discussion，p.19。

**对你的项目启发：**
如果你的系统要监测坐姿或康复姿态，不能默认 MediaPipe Pose 在所有人体方向上都稳定。尤其当身体方向与训练数据常见站立姿态不一致时，应考虑相机布置、图像预处理、关键点置信度过滤或模型微调。

### 4.2 不同身体姿态下，最佳模型不同

| 姿态         | 2D 最佳 / 作者结论                                                                                               | 3D 最佳 / 作者结论                         | 原文位置                |
| ---------- | ---------------------------------------------------------------------------------------------------------- | ------------------------------------ | ------------------- |
| Supine，旋转后 | AlphaPose；2D keypoint mean error 0.0386 ± 0.0301；2D angle MAE 9.12 ± 11.72°                                | HybrIK；3D angle MAE 6.92 ± 10.05°    | Figures 7–9，p.13–14 |
| Seated     | StridedTransformer-Pose3D 被作者作为最佳 2D 方法讨论；2D keypoint mean error 0.0326 ± 0.0163；2D angle MAE 6.54 ± 9.73° | HybrIK；3D angle MAE 7.29 ± 11.18°    | Figures 10–12，p.14  |
| Standing   | KAPAO；2D keypoint mean error 0.0334 ± 0.0103；2D angle MAE 11.48 ± 17.01°                                   | MediaPipe；3D angle MAE 11.96 ± 9.99° | Figures 13–15，p.15  |

位置：Results 5.2，p.13–15；Conclusions，p.20–21。

**注意：**
这说明模型选择与人体姿态相关。对你的系统而言，坐姿颈椎监测不一定需要直接采用本文的“最佳模型”，但应该借鉴其做法：**按场景姿态分别验证模型误差，而不是只报告整体平均性能**。

### 4.3 相机视角显著影响估计误差

作者使用 ANOVA 分析相机视角影响，报告 p-value 近似为 0.0，并进一步用 Tukey test 显示相机之间存在显著差异。

关键结果：

| 指标                        | 最优趋势                                         | 数值位置           |
| ------------------------- | -------------------------------------------- | -------------- |
| 2D keypoint mean error    | cam1 最低：0.0389；cam3 最高：0.0667                | Figure 17，p.17 |
| 2D angle MAE 全模型平均        | cam0：11.4°；cam1：11.8°；cam3：13.56°            | Figure 16，p.17 |
| 3D angle MAE 全模型平均        | cam1：14.39°；cam3：18.4°                       | Figure 16，p.17 |
| 2D-vs-3D angle comparison | Camera AVG：cam0 7.38°，cam1 8.99°，cam3 12.04° | Table 8，p.18   |

位置：Results 5.3，p.15–17；Tables 5–7，p.16；Figure 16–17，p.17；Table 8，p.18。

**对你的项目启发：**
你的颈椎 / 脊柱姿态监测系统应优先规定摄像头安装视角，例如正前方或侧前方，并在 Evaluation 中报告不同视角下 CVA、head pitch、头前伸距离或躯干前倾误差。本文不能直接给出颈椎角度误差，但强烈支持“相机视角必须作为实验变量控制”。

---

### 4.4 2D 姿态估计在特定条件下可用于角度估计

作者比较 2D 模型角度与 3D ground truth 角度，在部分下肢动作中得到如下 model average MAE：

| 2D 模型                             | Model AVG MAE |
| --------------------------------- | ------------: |
| AlphaPose                         |         6.75° |
| KAPAO                             |         7.84° |
| VideoPose3D base 2D               |         9.11° |
| MediaPipe                         |         9.36° |
| StridedTransformer-Pose3D base 2D |         9.88° |
| HMR                               |        13.84° |

位置：Table 8，p.18。

作者结论认为，在选定相机视角下，2D pose estimators 对关节角度估计是可用的；但误差受模型和相机方向影响很大。

位置：Abstract，p.1；Results 5.4，p.17–18；Discussion，p.19；Conclusions，p.20–21。

**重要限制：**
这个结论只适用于本文实验中的**肢体康复动作角度**，不能直接推广到 CVA、head pitch 或颈椎曲度评估。

---

### 4.5 MediaPipe 的实际工程价值

虽然 MediaPipe 并非所有指标中误差最低，但作者在结论中推荐 MediaPipe 作为未来康复系统的姿态估计方法，原因是它容易集成到 Android、iOS、JavaScript、Python 等平台，并且同时提供 2D 和 3D 估计，误差也相对较低。

位置：Conclusions，p.21。

**对你的项目启发：**
这可以作为你选择 MediaPipe Pose 的工程依据，但不能作为 MediaPipe Face Landmarker 或 head pitch 精度依据。你仍需要单独验证 head pitch 和 CVA。

## 5. 这篇文献的贡献

### 5.1 它解决了什么问题？

1. 提供了一个面向物理康复动作的 RGB 视频数据集；
2. 用 OptiTrack 作为 3D ground truth，为单目 RGB 姿态估计提供验证基础；
3. 系统比较多个 2D / 3D HPE 方法在康复动作中的误差；
4. 量化分析人体姿态和相机视角对估计误差的影响；
5. 探讨 2D 姿态估计在角度测量中是否足够。

### 5.2 相比已有研究的改进

作者认为已有康复数据集很多不包含 RGB video，只提供 skeleton、depth map 或其他专用数据，因此不利于训练 / 微调 / 评估 RGB-based HPE 方法。本文的数据集包含 RGB 视频、不同相机视角和 OptiTrack ground truth。

位置：Introduction，p.2；Discussion，p.19。

## 6. 这篇文献的局限

### 6.1 作者自己提到的 limitation

| 局限                                                 | 原文位置                          |
| -------------------------------------------------- | ----------------------------- |
| OptiTrack ground truth 需要满足固定传感器位置和受控光照条件          | Discussion，p.19               |
| OptiTrack 在某些传感器被遮挡时会丢失关节点                         | Materials，p.5；Discussion，p.19 |
| 数据在受控环境、固定背景下采集，可能限制对非受控场景的适用性                     | Discussion，p.19               |
| 动作范围仅对应当前目标康复动作，未来需要增加新动作和更多被试                     | Discussion，p.19–20            |
| 评估的方法是通用 HPE 模型，不是针对物理康复训练的专门模型                    | Discussion，p.20               |
| 即使表现最好的方法也会出现 occlusion、limb misidentification 等错误 | Figure 19，p.20                |
| 未来需要 fine-tuning 或训练特定姿态 / 动作模型，尤其是 supine 姿态      | Conclusions，p.21              |

### 6.2 对你的项目有影响的 limitation

1. **不是颈椎姿态论文**
   文中没有 CVA、head pitch、头前伸距离、躯干前倾，也没有颈椎康复风险分级。

2. **ground truth 不是 RGB-D**
   本文使用 OptiTrack IR motion capture。你可以借鉴验证框架，但不能写成“本文证明 RGB-D 可作为 ground truth”。

3. **被试是健康人，不是真实颈椎病或康复患者**
   文中记录的是 healthy subjects。你的系统如果用于康复指导，需要额外验证患者群体。

4. **没有临床动作质量评分模型**
   本文评估的是关键点和角度误差，没有建立动作质量评分、DTW 模板匹配或风险等级。

5. **没有实时反馈系统**
   文中没有 Unity avatar、digital twin、实时纠错界面或用户交互系统。

### 6.3 哪些结论不能过度引用？

| 不能过度引用的说法                            | 正确写法                                                                     |

## 7. 我可以在论文中如何使用这篇文献？

### 7.1 Introduction 中怎么用

你可以用它支持以下论点：

* 康复训练需要远程 / 家庭场景下的自动化监测；
* RGB camera-based 方法比 wearables 或专用设备更低侵入；
