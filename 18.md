## 2. 这篇文献研究了什么问题？

### Research question / aim

这篇文章的核心目标是发布并描述 **KneE-PAD** 数据集：一个用于膝关节康复动作姿态评估的数据集。数据来自 **31 名膝关节病理患者**，他们完成 3 类常见下肢康复动作：**深蹲、坐姿膝伸展、步态/行走**。每个动作包含正确执行和两类常见错误执行方式，数据由 **8 个 Delsys Trigno Avanti sEMG + IMU 可穿戴传感器**同步采集。

作者希望该数据集可用于训练机器学习算法，实现仅基于可穿戴传感器的自动姿态评估，并进一步用于虚拟教练或远程康复反馈系统。
**位置：Abstract，第 1 页；Background & Summary，第 1–2 页。**

---

### 为什么这个问题重要？

文中指出，膝关节损伤或骨科疾病患者在医院或康复中心接受面对面康复后，通常需要在家中继续约 3 个月的康复训练，但这一阶段往往缺少物理治疗师监督，因此患者依从性和动作质量难以保证。作者认为，虚拟助手、VR/XR、ML-based coach 等远程系统可以帮助患者在家中获得动作监督和反馈。
**位置：Background & Summary，第 1 页。**

### 3.5 实验流程

1. 数据采集持续 **6 个月**。
2. 采集地点为 **2 个康复中心**。
3. 患者佩戴 8 个 sEMG + IMU 传感器。
4. 患者在**没有物理治疗师监督**的情况下完成康复动作，以模拟居家康复环境。
5. 每位患者执行 3 类康复动作：

   * Squat
   * Seated leg extension
   * Gait / Timed Up and Go-like walking task
6. 每个动作要求重复 **10 次**。
7. 作者结合可穿戴数据、RGB 视频和 goniometer 膝关节角度，对错误执行动作进行整理和分组。
8. 最终为每个动作确定 2 类常见错误变体。

**位置：Acquisition protocol，第 3–4 页。**

### 3.9 算法或统计方法

本文不是一个机器学习模型性能论文，没有训练分类器或报告模型准确率。技术验证部分主要通过 **Exploratory Data Analysis, EDA** 检查数据是否具有合理的生物力学解释。

使用的统计特征包括：

* sEMG 标准差；
* healthy leg 与 injured leg 之间的 sEMG 欧氏距离；
* 加速度欧氏距离；
* 加速度最大值；
* 加速度标准差；
* kurtosis。

**位置：Technical Validation，第 7–9 页；Figure 7，第 9 页。**

### 3.10 Ground truth 是什么？

需要区分两层含义：

| 问题                               | 文中情况                                                     |
| -------------------------------- | -------------------------------------------------------- |
| 动作类别 ground truth                | 作者通过可穿戴数据、RGB 视频和 goniometer 膝角度进行离线整理与标注，形成 Class ID 标签 |
| 关节角度 ground truth                | **文中未提供**                                                |
| 3D pose ground truth             | **文中未提供**                                                |
| RGB-D ground truth               | **KneE-PAD 本身未提供**                                       |
| motion capture ground truth      | **文中未提供**                                                |
| 标注者一致性 / inter-rater reliability | **文中未明确说明**                                              |

作者在 limitation 中明确指出，如果加入 vision markers，会有助于捕获患者关节角度 ground truth，从而使数据集也可用于 3D pose estimation 算法开发。

### 4.3 需要注意的“结果边界”

本文没有给出模型训练结果，因此不能写成：

> “KneE-PAD achieved high accuracy in rehabilitation exercise recognition.”

更稳妥的写法是：

> “The authors performed exploratory data analysis and showed that the extracted sEMG and IMU features exhibited biomechanically interpretable differences across correct and incorrect rehabilitation exercise executions.”

## 5. 这篇文献的贡献

### 5.1 它解决了什么问题？

本文主要解决的是：**缺少来自真实患者、同时包含 sEMG 和 IMU、并面向康复动作姿态评估的公开数据集**。

作者指出，已有可穿戴数据集通常面向 human activity recognition 或 lower-limb joint angle estimation，而不是康复动作姿态评估；一些康复数据集使用健康受试者模拟错误动作，不能充分代表真实患者的动作模式和肌肉激活异常。
**位置：Background & Summary，第 1–2 页；Comparison，第 8–9 页。**

---

### 5.2 相比已有研究的改进

| 方面   | 改进点                                              |
| ---- | ------------------------------------------------ |
| 被试来源 | 使用膝关节病理患者，而不是只使用健康人模拟错误动作                        |
| 数据模态 | 同时提供 sEMG 和 IMU                                  |
| 应用目标 | 面向 postural assessment，而不仅是 activity recognition |
| 标签设计 | 提供正确动作和常见错误动作变体                                  |
| 采集环境 | 在康复中心中无监督执行，试图模拟居家康复环境                           |
| 开放性  | 数据发布到 Zenodo，代码发布到 GitHub                        |

### 6.3 哪些结论不能过度引用？

不要把本文写成以下结论：

1. **不能说**本文证明了单目视觉可以准确估计康复动作。
   因为本文主要基于 sEMG 和 IMU，不是单目 RGB。

2. **不能说**本文提供了 RGB-D ground truth。
   文中只说 RGB camera 和 goniometer 用于离线标注，且这些数据不在 KneE-PAD 中提供。

3. **不能说**本文验证了 MediaPipe。
