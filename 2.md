## 2. 这篇文献研究了什么问题？

### 2.1 Research question / aim

本文的核心问题是：

> 一个基于 computer vision 的 smartphone application 是否能够可靠、有效地测量 craniovertebral angle, CVA，从而用于 forward head posture, FHP 的评估？

作者在 Introduction 末尾明确提出两个目标：

1. 分析 CVA-CVapp 在健康人、颈痛患者、紧张型头痛患者中的 **test-retest reliability** 和 **inter-rater reliability**；
2. 将 CVA-CVapp 与 **2D Kinovea software** 进行比较，分析其 **concurrent validity**。
   位置：PDF p.2, Introduction 末段。

### 2.2 为什么这个问题重要？

作者认为 CVA 是评估 forward head posture 的常用量化指标。FHP 可能与颈痛、肩部疼痛、头痛、颈椎肌肉张力增加，以及长期使用电子设备和久坐有关。文中还提到，CVA 小于 **50–53°** 曾被描述为 FHP 的 cut-off value。
位置：PDF p.1–2, Introduction。

此外，作者指出 COVID-19 后 telerehabilitation 增长，而计算机视觉和 AI 技术使得通过图像自动提取姿态信息成为可能。但要真正进入临床康复场景，相关工具必须先证明其 valid and reliable。
位置：PDF p.2, Introduction。

## 3. 方法细节

### 3.1 被试 / 数据集 / 样本量

| 项目       | 内容                                                                                    |
| -------- | ------------------------------------------------------------------------------------- |
| 总样本量     | 42 人                                                                                  |
| 分组       | 14 名健康对照，14 名颈痛患者，14 名紧张型头痛患者                                                         |
| 年龄范围     | 18–65 岁                                                                               |
| 招募来源     | Sant Cugat del Vallès metropolitan area 和 Universitat International de Catalunya 大学社区 |
| 健康对照定义   | 最近 3 个月无颈痛                                                                            |
| 颈痛组定义    | 有颈部疼痛且 NDI > 10 points                                                                |
| 紧张型头痛组定义 | 最近一周内咨询医生，并符合 International Criteria for Headache Disorders 中 TTH 标准                  |
| 排除标准     | whiplash injury、cervical spinal arthrodesis、tinnitus、vertigo、dizziness、unsteadiness   |

位置：PDF p.3, Sections 2.2–2.3。

### 3.2 使用的设备或传感器

| 项目           | 内容                                       |
| ------------ | ---------------------------------------- |
| 主设备          | 手机 + CVA-CVapp                           |
| 图像方式         | 侧面照片 / photometry                        |
| 摄像头距离        | 相机置于固定底座，距离被试 1.5 m                      |
| 摄像头高度        | 调整到被试肩部高度                                |
| 标记点          | 两个红色 marker：C7 和 ear tragus              |
| 对照工具         | Kinovea software                         |
| RGB-D sensor | 文中未使用                                    |
| MediaPipe    | 文中未使用                                    |
| 具体手机型号       | 文中未明确说明；Discussion 中提到只使用了 single device |

位置：PDF p.4, Section 2.4.1；PDF p.7, Limitations。

### 3.3 测量指标

| 指标            | 作用                             |
| ------------- | ------------------------------ |
| CVA           | 核心指标，用于评估 forward head posture |
| VAS neck pain | 颈痛强度                           |
| VAS headache  | 头痛强度                           |
| HIT-6         | 头痛影响程度                         |
| NDI           | 颈部功能障碍程度                       |
| ROM           | 文中提到记录，但结果部分没有作为核心分析展开         |

CVA 定义为：
**通过 C7 的水平线与 tragus-to-C7 连线之间形成的角度。**
位置：PDF p.4, Section 2.4.1。

### 3.4 实验流程

1. 每位被试参加两次 assessment sessions；
2. 两次 session 间隔 1 周；
3. 第一场记录年龄、身高、体重、BMI 等人口学数据；
4. 两次 session 均记录 CVA、ROM、pain intensity、HIT-6、NDI；
5. CVA 测量中，被试保持 relaxed position，并 look straight ahead；
6. 每次 session 中，两个独立物理治疗师使用 CVA-CVapp 测量 CVA；
7. inter-rater reliability 中，两名 examiner 分别放置 marker，间隔 30 分钟，且互不在场；
8. test-retest reliability 在一周后重复测量，由更有经验的 examiner 完成；
9. concurrent validity 中，specialist examiner 同时用 CVA-CVapp 记录 CVA，并拍照后用 Kinovea 进行比较。

位置：PDF p.2–4, Sections 2.1 and 2.4.1；Figure 1 位于 PDF p.3。

### 3.5 算法或统计方法

| 方法                              | 用途                                                |
| ------------------------------- | ------------------------------------------------- |
| ICC with 95% CI                 | test-retest reliability 和 inter-rater reliability |
| SEM                             | standard error of measurement                     |
| MDC                             | minimum detectable change                         |
| Pearson correlation coefficient | CVA-CVapp 与 Kinovea 的 concurrent validity         |
| Bland–Altman plot               | 显示两个工具之间的一致性情况                                    |
| SPSS 20.0                       | 统计分析软件                                            |

SEM 公式：
**SEM = SD × √(1 − ICC)**

MDC 公式：
**MDC = SEM × 1.96 × √2**

位置：PDF p.4–5, Section 2.5。

### 3.6 Ground truth 是什么？

严格来说，本文没有使用 RGB-D、X-ray 或 motion capture 作为 ground truth。

本文用于 concurrent validity 的参考工具是：

> **2D Kinovea software based on photometry**

作者在 Introduction 中称 photometry 是评估 head position 的 “gold standard”，但在本实验中，具体对照对象是 Kinovea。
位置：PDF p.2, Introduction；PDF p.4, Section 2.4.1；PDF p.6, Table 4。

| 评价指标                          |            文中是否使用 | 说明                                      |

### 4.3 Test-retest reliability

位置：PDF p.5, Table 2。

| 组别                    | Assessment 1 CVA-CVapp mean ± SD | Assessment 2 CVA-CVapp mean ± SD |      ICC 95% CI |  SEM |  MDC |

位置：PDF p.6, Table 4。

| 工具        | CVA mean ± SD |
| --------- | ------------: |
| Kinovea   |  53.71 ± 6.39 |

**关键结论：**
CVA-CVapp 与 Kinovea 的 CVA 测量结果高度相关。作者将其解释为 strong correlation。

## 5. 这篇文献的贡献

### 5.1 它解决了什么问题？

它验证了一个基于 computer vision 的 smartphone application 是否可以用于 CVA 自动测量，并证明该工具在 standing position 下具有较好的 reliability 和 concurrent validity。

### 5.2 相比已有研究有什么改进？

作者在 Discussion 中将 CVA-CVapp 与 FHPapp 进行了比较：

| 工具        | 操作方式                                        |
| --------- | ------------------------------------------- |
| FHPapp    | 拍照后，治疗师需要在照片上手动放置 3 个点/线来计算 CVA             |
| CVA-CVapp | 治疗师只需在 C7 和 tragus 放置两个 marker，app 自动计算 CVA |

位置：PDF p.7, Discussion。

因此，本文贡献不是提出无标记人体关键点检测，而是将 CVA 测量流程进一步自动化，降低手动后处理负担。

### 5.3 对你的项目的启发

| 对你的项目的启发                    | 具体说明                                                                                 |
| --------------------------- | ------------------------------------------------------------------------------------ |
| CVA 是合理的核心颈椎姿态指标            | 本文说明 CVA 被广泛用于 FHP 量化，可支持你把 CVA 放入指标体系。                                              |
| 单目 RGB 图像可以用于颈椎姿态评估         | 本文用手机图像 + CV app 得到高可靠性结果，可作为你的单目视觉方案的背景依据。                                          |
| 需要报告 reliability 与 validity | 你的系统如果测 CVA、head pitch、前伸距离，也应报告 ICC、MAE/误差、Pearson r、Bland–Altman 等。                |
| 需要明确 reference standard     | 本文用 Kinovea 作为 concurrent validity 参考；你的项目使用 RGB-D sensor 作为 ground truth，可以比本文更进一步。 |
| 需要报告 MDC/SEM                | 本文的 MDC 约 5°，提示你在风险分级中不要把过小的 CVA 波动解释为真实姿态变化。                                        |
| 坐姿场景需要单独验证                  | 本文只验证 standing position，而你的系统主要关注坐姿监测，所以不能直接迁移其结论。                                   |

## 6. 这篇文献的局限

### 6.1 作者自己提到的 limitations

位置：PDF p.7, Discussion；PDF p.7, Conclusions。

| Limitation       | 说明                                                         |
| ---------------- | ---------------------------------------------------------- |
| 样本类型有限           | 只包括 healthy controls、neck pain、TTH，不能外推到 whiplash 等其他颈椎患者。 |
| 姿势条件有限           | 只在 standing position 下评估，不知道 sitting position 是否有相同结果。     |
| 依赖 marker 放置     | 如果 marker 或患者位置错误，会影响结果。                                   |
| 需要培训             | 需要事先训练如何放置 marker 和使用 app。                                 |
| App 仍在开发中        | 作者明确提到 application is still under development。             |
| 只用 single device | 不能证明不同手机/摄像头设备上的泛化能力。                                      |
| 其他变量未分析          | 虽然记录了 pain 和 headache impact，但没有分析这些变量是否影响测量结果。            |
| 只测 CVA           | 结论不能扩展到其他 cervical angles。                                 |

| 对你的项目的影响                           | 解释                                                          |
| ---------------------------------- | ----------------------------------------------------------- |
| 不能直接证明坐姿监测有效                       | 你的系统主要是坐姿/办公场景，本文 standing-only 是重要限制。                      |
| 不能证明 markerless 方法有效               | 本文需要 C7 和 tragus 红色 marker，而你的 MediaPipe 方案大概率是 markerless。 |

| 不能支持 head pitch                    | 本文没有 Face Landmarker，也没有 pitch angle。                       |
| 不能支持动作识别或康复动作评分                    | 本文是静态 CVA 测量，不是动作识别或 DTW 研究。                                |
| 不能直接支持 digital twin / Unity avatar | 文中未涉及实时 3D 可视化反馈。                                           |

### 6.3 哪些结论不能过度引用？

不要写成：

* “Computer vision can accurately assess all cervical posture parameters.”
  **原因：** 文中只验证 CVA。
* “Markerless RGB pose estimation is validated for CVA.”
  **原因：** 本文使用两个红色 markers，不是 markerless MediaPipe。
* “The method is validated for sitting posture monitoring.”
  **原因：** 本文只测试 standing position。
* “The app was validated against RGB-D ground truth.”
  **原因：** reference 是 Kinovea，不是 RGB-D。
* “The system can guide rehabilitation exercises.”
  **原因：** 本文没有动作识别或康复指导实验。

## 8. 可直接改写进论文的英文句子

1. **Image-based assessment of the craniovertebral angle has been investigated as a practical approach for quantifying forward head posture in clinical and telerehabilitation contexts.**
   适合章节：Introduction / Related Work

2. **Carrasco-Uribarren et al. validated a smartphone-based computer vision application for CVA measurement and reported excellent test-retest and inter-rater reliability in healthy participants, patients with neck pain, and patients with tension-type headache.**
   适合章节：Related Work

3. **Their study used Kinovea-based photometric measurement as the reference method for concurrent validity, reporting a strong correlation between the smartphone application and Kinovea measurements.**
   适合章节：Related Work / Evaluation
